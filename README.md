# First Vibe Project

Простое сайт-приложение для записи учеников на занятия по вождению.

## Что умеет

- выбор даты и свободного времени;
- ввод данных ученика в боковой панели после выбора времени;
- плашка успешной записи после отправки формы;
- выбор инструктора;
- стартовый экран выбора роли: ученик или инструктор;
- простой вход инструктора по логину и паролю;
- настройки расписания для инструктора: рабочие дни, начало и конец дня, длительность занятия;
- кабинет инструктора с журналом, редактированием и удалением заявок;
- сохранение заявок в браузере через `localStorage`;
- экспорт заявок в CSV.

## Как открыть

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 5173
```

После этого откройте общий вход:

`http://localhost:5173/index.html`

Тестовый вход инструктора:

- логин: `instructor`;
- пароль: `1234`.

## Важно

Это первая рабочая версия без backend-сервера. Сейчас заявки, настройки и тестовая сессия инструктора сохраняются в браузере через `localStorage`. Для настоящего разделения доступа в интернете следующим шагом нужен backend, база данных, безопасная авторизация инструктора и уведомления в Telegram, email или WhatsApp.
