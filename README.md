# First Vibe Project

Простое сайт-приложение для записи учеников на занятия по вождению.

## Что умеет

- выбор даты и свободного времени;
- форма ученика с именем, телефоном, email и комментарием;
- выбор инструктора;
- сохранение заявок в браузере через `localStorage`;
- журнал заявок для владельца;
- экспорт заявок в CSV.

## Как открыть

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 5173
```

После этого сайт будет доступен по адресу `http://localhost:5173`.

## Важно

Это первая рабочая версия без backend-сервера. Сейчас заявки сохраняются в браузере на устройстве владельца. Для настоящего приема заявок от клиентов в интернете следующим шагом нужен backend, база данных и уведомления в Telegram, email или WhatsApp.
