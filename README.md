# First Vibe Project

Простое сайт-приложение для записи учеников на занятия по вождению.

## Что умеет

- выбор даты и свободного времени;
- ввод данных ученика в боковой панели после выбора времени;
- плашка успешной записи после отправки формы;
- выбор зарегистрированного инструктора или варианта "любой свободный инструктор";
- стартовый экран выбора роли: ученик или инструктор;
- регистрация инструктора с именем, контактами, логином и паролем;
- вход инструктора по созданному логину и паролю;
- отдельные настройки расписания для каждого инструктора: рабочие дни, начало и конец дня, перерыв, длительность занятия, ограничение записи по времени;
- закрытие отдельных дат для выходных, отпуска или экзаменов;
- настройки каналов уведомлений и список ближайших напоминаний;
- недельный календарь занятий инструктора;
- мини-аналитика по заявкам, загрузке недели и email-согласиям;
- кабинет инструктора с журналом, редактированием и удалением только своих заявок;
- сохранение заявок, инструкторов и расписаний в браузере через `localStorage`;
- экспорт заявок в CSV.

## Как открыть

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 5173
```

После этого откройте общий вход:

`http://localhost:5173/index.html`

Чтобы войти как инструктор, сначала создайте кабинет через кнопку "Создать кабинет", затем используйте свой логин и пароль.

## Supabase backend

Проект умеет работать в двух режимах:

- без Supabase: данные хранятся в браузере через `localStorage`;
- с Supabase: данные синхронизируются с таблицами `instructors` и `bookings`.

Чтобы включить Supabase:

1. В Supabase откройте **SQL Editor**.
2. Вставьте и выполните SQL из файла `supabase/schema.sql`.
3. Откройте **Project Settings -> Data API / API Keys**.
4. Скопируйте `Project URL` и `anon public key`.
5. Вставьте их в `supabase-config.js`:

```js
window.DRIVEBOOK_SUPABASE = {
  url: "https://your-project.supabase.co",
  anonKey: "your-anon-public-key",
};
```

`service_role key` нельзя вставлять во frontend-файлы и нельзя коммитить в GitHub. Он понадобится позже только для backend-функций и Telegram/email-уведомлений.

## Важно

Это первая рабочая версия без полноценной безопасной авторизации. Supabase-режим сделан для тестирования общей базы и переноса данных с компьютера на сервер. Для продакшена следующим шагом нужно заменить тестовый логин/пароль на Supabase Auth или отдельный backend и ужесточить RLS-политики.
