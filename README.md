# First Vibe Project

Простое сайт-приложение для записи учеников на занятия по вождению.

## Что умеет

- выбор даты и свободного времени;
- форма ученика с именем, телефоном, email и комментарием;
- выбор инструктора;
- настройки расписания для инструктора: рабочие дни, начало и конец дня, длительность занятия;
- отдельная страница ученика без доступа к журналу и настройкам;
- отдельный кабинет инструктора с журналом, редактированием и удалением заявок;
- сохранение заявок в браузере через `localStorage`;
- экспорт заявок в CSV.

## Как открыть

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python3 -m http.server 5173
```

После этого доступны две страницы:

- ученик: `http://localhost:5173/index.html`;
- инструктор: `http://localhost:5173/instructor.html`.

## Важно

Это первая рабочая версия без backend-сервера. Сейчас заявки и настройки сохраняются в браузере через `localStorage`. Для настоящего разделения доступа в интернете следующим шагом нужен backend, база данных, авторизация инструктора и уведомления в Telegram, email или WhatsApp.
